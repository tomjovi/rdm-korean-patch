# Remote Desktop Manager 한국어 패치 (비공식) — 설치

대상: RDM win-x64 2026.3.10.0 (패치 2026.3.10.2)
포함: ko\Devolutions.Resources.resources.dll , deps-ko-snippet.txt

이 패치는 Devolutions 공식 제품이 아닙니다. 보증·지원이 없으며, 적용 전 반드시 백업하세요.


## 설치 (대부분 이 단계만으로 충분합니다)

1. Remote Desktop Manager를 완전히 종료합니다.
   - 트레이(알림 영역) 아이콘까지 종료하세요.

2. RDM 설치(또는 포터블) 폴더를 찾습니다.
   - 폴더 안에 Devolutions.Resources.dll 이 있으면 그곳이 루트입니다.
   - 예: C:\Program Files\Devolutions\Remote Desktop Manager\

3. 이 zip의 ko 폴더 전체를 RDM 루트 아래에 복사합니다.

     (RDM 루트)\
       Devolutions.Resources.dll          ← 원래 있음
       ko\
         Devolutions.Resources.resources.dll   ← 이 zip에서 복사

4. RDM을 실행한 뒤, 설정에서 UI 언어를 한국어(ko)로 선택합니다.
   - Windows 표시 언어가 한국어면 자동으로 잡히는 경우도 있습니다.
   - 메뉴·메시지 등이 한글로 보이면 성공입니다.
   - 패치 버전 확인: 도움말 → 소개(저작권 줄), 또는 제품 버전 라벨에
     「한국어 패치 2026.3.10.2」가 보이면 이 패치가 적용된 상태입니다.


## (선택) 한국어가 안 보일 때만 — deps.json 등록

대부분의 경우 ko 폴더만 있으면 .NET이 한국어 DLL을 자동으로 읽습니다.
폴더를 넣었는데도 UI가 영어로 남으면, 아래를 시도하세요.

1. RDM 루트에서 다음 파일 중 하나를 메모장으로 엽니다.
   - Devolutions.Resources.deps.json
   - 또는 RemoteDesktopManager.deps.json

2. 파일 안의 "resources" 구간에, 같은 zip의 deps-ko-snippet.txt 내용을 추가합니다.
   추가할 내용(기존 항목이 있으면 쉼표로 구분):

     "ko/Devolutions.Resources.resources.dll": {
       "locale": "ko"
     }

3. 저장 후 RDM을 다시 실행합니다.

* deps.json은 .NET이 “어느 언어 DLL을 로드할지” 적어 둔 목록입니다.
  필수 단계는 아니며, 위성 폴더만으로 로드가 안 될 때의 보조 조치입니다.


## 롤백 (원래대로 되돌리기)

- RDM을 종료한 뒤, 넣은 ko 폴더를 삭제하거나 이름 변경합니다.
- deps.json을 수정했다면 추가한 ko 항목도 제거합니다.
- RDM을 다시 실행하면 됩니다.


## 주의

- 다른 RDM 버전에서는 일부 문구가 영문으로 남거나 로드에 실패할 수 있습니다.
